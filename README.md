## 8 月那次改动，把 Go 的核心卖点改没了

8 月 6 日，OpenAI 宣布免费版和 Go 档的文字对话全部不限量，当周（8 月 10 日那一周）开始推送，默认模型统一为 GPT-5.6 Luna。在这之前，Go 的宣传语一直是“大约十倍于免费版的消息额度”——免费额度一变成无限，“十倍无限”这个说法就写不下去了。

不过“无限”两个字覆盖的范围比看起来小：

- **只有文本不限量。** 文件上传、图片上传、生图、语音，在免费版和 Go 上都保留各自的额度上限。
- 深度推理不在这波免费范围里。免费版和 Go 新增了一个 Think 按钮，遇到难题会多花点时间琢磨；但完整的推理模型 GPT-5.6 Sol 和推理强度滑块，仍然锁在 Plus 以上。

所以局面变成了：免费版在 Go 唯一的招牌功能上追平了它，而 Go 本质上还是那个“砍掉高级功能换低价”的精简套餐。

## $8 现在还能买到什么

Go 保留的东西不算少，只是性质变了——从“解锁”变成了“加量”：

- 文件上传和生图额度大约是免费版的十倍，语音额度也更高
